# 产品运营与用户增长诊断工作台

v0.36 · 可交互作品集原型

面向产品运营与用户增长运营的工作台，串联经营总览、用户旅程、功能体验、留存分析、活动诊断与改进复盘。

## 展示路径

经营总览 → 用户旅程 / 活动与增长 → 改进与复盘 → 执行与沉淀。

- 七个主模块，活动模块内包含四个分页。
- 支持筛选、漏斗分析、改进记录、执行跟进、交接验收和备份。
- 适配桌面与手机，支持键盘操作和减少动态效果。

## 项目边界

这是使用内置模拟数据的交互原型，不代表企业实绩。记录保存在访问者自己的浏览器中，不会自动上传或同步给其他人。页面不包含团队登录、服务端数据库或通知服务。

## 部署

将本目录提交至 GitHub 仓库。进入 Settings → Pages，选择 Deploy from a branch，发布 main 分支的根目录即可。无需安装依赖或构建。
